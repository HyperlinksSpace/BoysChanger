How does BoysChanger work?

  1. Supercharge your mic path Install the bundled virtual cable (Windows) or BlackHole (macOS). BoysChanger writes processed audio into it.
  2. Point apps at the cable In Telegram / Discord / games, set the microphone to CABLE Output or BlackHole — not your hardware mic.
  3. Blow minds Pick a voice, flip ON, drop sounds. The tray icon tells your squad (and you) when you’re live.

Quick setup

Windows

  1. Install BoysChanger → use Install virtual cable (bundled VB-CABLE), reboot if asked.
  2. Input = real mic · Output = CABLE Input.
  3. Click Setup for Telegram (or Apply as system input).
  4. In Telegram: Call settings → Microphone = CABLE Output. Rejoin the chat.

macOS

  1. Install BlackHole 2ch, then BoysChanger.
  2. Input = real mic · Output = BlackHole 2ch.
  3. Apply as system input (or set Sound → Input to BlackHole).
  4. In Telegram: Call settings → Microphone = BlackHole. Rejoin the chat.
