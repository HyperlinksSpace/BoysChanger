Cute like Voicemod. Free like open source.

Full-screen library, free Voice Studio, tray icon that turns red when you’re off.

  • Colorful voice library Built-in characters plus voices you save locally in Studio.
  • Voice Studio — always free Race, gender, age, timbre, FX — craft and keep voices on your device.
  • Soundboard + prehear Upload MP3s and replay the last 11 seconds before you go live.
  • Tray stays with you System tray icon stays after close; green when ON, red when OFF.

Quick setup

Windows

  1. Install VB-Cable and reboot.
  2. Install BoysChanger from the latest release.
  3. Set Output to CABLE Input.
  4. Click Apply as system input (or set default mic to CABLE Output).
  5. Flip the changer ON.

macOS

  1. Install BlackHole 2ch.
  2. Install BoysChanger from the latest release.
  3. Set Output to BlackHole 2ch.
  4. Click Apply as system input (or set input to BlackHole in Sound settings).
  5. Flip the changer ON.
